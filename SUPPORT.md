# Getting Support

For the fastest help, use the support channel appropriate to your request.

- **Bug reports:** open an issue using the bug report template in the affected repository.
- **Feature ideas:** open a feature request or discussion in the affected repository.
- **Usage and integration questions:** consult the project's documentation first, then use the official community channel.
- **Security concerns:** follow [`SECURITY.md`](SECURITY.md); do not post vulnerabilities publicly.
- **Private or account-specific matters:** use an official support contact after it has been published.

Replace the following placeholders before publishing:

- Documentation: `https://YOUR_DOCS_URL`
- Community: `https://YOUR_COMMUNITY_URL`
- Support email: `SUPPORT_EMAIL`
